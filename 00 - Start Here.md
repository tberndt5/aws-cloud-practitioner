# AWS Certified Cloud Practitioner (CLF-C02): Start Here

Built from the official [CLF-C02 exam guide](https://d1.awsstatic.com/training-and-certification/docs-cloud-practitioner/AWS-Certified-Cloud-Practitioner_Exam-Guide.pdf) and the AWS CLF-C02 reference guide. Follow [[01 - Study Plan (14 Days)]] day by day.

## The exam in one table

| Item | Fact |
| --- | --- |
| Questions | 65 total: ==50 scored + 15 unscored== (unscored are not marked) |
| Time | 90 minutes |
| Question types | Multiple choice (1 of 4) and multiple response (2 or more of 5 or more) |
| Score | Scaled 100–1,000; ==pass at 700== |
| Scoring model | Compensatory: you pass on the overall score, not per domain |
| Guessing | No penalty; unanswered counts as wrong, so answer everything |
| Out of scope | Coding, architecture design, troubleshooting, implementation, load testing |

Official page: [AWS Certified Cloud Practitioner](https://aws.amazon.com/certification/certified-cloud-practitioner/)

> [!tip] How to review
> 1. First time only: Settings → Community plugins → **Turn on community plugins**, then switch on **Spaced Repetition** in the installed plugins list.
> 2. Click the card icon in the left ribbon (or Command palette → *Spaced Repetition: Review flashcards from all notes*).
> 3. Pick a deck, answer from memory, then grade yourself **Hard / Good / Easy**. The plugin schedules the next showing; cards you find hard come back sooner.
> 4. Do the due cards every day before reading anything new. The status bar shows how many are due.
