# 4.3 Identify AWS technical resources and AWS Support options

> [!abstract] Exam guide objective (verbatim from the CLF-C02 exam guide)
> **Knowledge of:**
> - Resources and documentation available on official AWS websites
> - AWS Support plans
> - Role of the AWS Partner Network, including independent software vendors and system integrators
> - AWS Support Center
>
> **Skills in:**
> - Locating AWS whitepapers, blogs, and documentation on official AWS websites
> - Identifying and locating AWS technical resources (for example AWS Prescriptive Guidance, AWS Knowledge Center, AWS re:Post)
> - Identifying AWS Support options for AWS customers (for example, customer service and communities, AWS Developer Support, AWS Business Support, AWS Enterprise On-Ramp Support, AWS Enterprise Support)
> - Identifying the role of Trusted Advisor, AWS Health Dashboard, and the AWS Health API to help manage and monitor environments for cost optimization
> - Identifying the role of the AWS Trust and Safety team to report abuse of AWS resources
> - Understanding the role of AWS Partners (for example AWS Marketplace, independent software vendors, system integrators)
> - Identifying the benefits of being an AWS Partner (for example, partner training and certification, partner events, partner volume discounts)
> - Identifying the key services that AWS Marketplace offers (for example, cost management, governance and entitlement)
> - Identifying technical assistance options available at AWS (for example, AWS Professional Services, AWS Solutions Architects)

## Big picture

This objective is about where to get help. The most tested part is the five AWS Support plans: the exam gives a requirement (a 15-minute response for a business-critical outage, a designated Technical Account Manager, the full set of Trusted Advisor checks, the lowest-cost plan with 24/7 phone access) and asks for the cheapest plan that meets it. Other questions match a need to a resource: re:Post for community answers, the Knowledge Center for common support questions, Prescriptive Guidance for proven migration patterns, the Trust and Safety team for abuse reports, the AWS Health Dashboard for events affecting your account, and AWS Partners or AWS Marketplace for third-party help and software. Learn the plans exactly as the 2023 reference guide shows them; AWS has since changed the lineup (see the Current status note), but the exam still uses the five classic plans.

## Key concepts

### AWS Support plans (exam version)

The reference guide's comparison table has four columns (Basic, Developer, Business, Enterprise). Enterprise On-Ramp is in the exam guide and sits between Business and Enterprise. Response times are the times for a first response from AWS, by case severity.

| Feature | Basic | Developer | Business | Enterprise On-Ramp | Enterprise |
| --- | --- | --- | --- | --- | --- |
| Cost | Free, included for all customers | Paid, lowest tier | Paid | Paid | Paid, highest |
| Technical support cases | ==None== (account and billing, and service quota increases only) | Business-hours **email** access to Cloud Support Associates | ==24/7 phone, web, and chat== to Cloud Support Engineers | 24/7 phone, web, and chat | 24/7 phone, web, and chat |
| Trusted Advisor | ==Core checks== (service quotas and basic security) | Core checks (service quotas and basic security) | ==All checks== | All checks | All checks |
| General guidance | | < 24 **business** hours | < 24 hours | < 24 hours | < 24 hours |
| System impaired | | < 12 **business** hours | < 12 hours | < 12 hours | < 12 hours |
| Production system impaired | | | < 4 hours | < 4 hours | < 4 hours |
| Production system down | | | ==< 1 hour== | < 1 hour | < 1 hour |
| Business-critical system down | | | | ==< 30 minutes== | ==< 15 minutes== |
| Technical Account Manager (TAM) | | | | ==Pool of TAMs== | ==Designated TAM== |
| Concierge Support Team (billing and account specialists) | | | | Yes | Yes |
| Infrastructure Event Management | | | Additional fee | One per year | Included |
| AWS Health API, AWS Support API | | | Yes | Yes | Yes |

Other things to know:

- **Basic Support** is free for every account and includes: 24/7 customer service for account and billing questions, documentation, whitepapers, AWS re:Post, the AWS Health Dashboard, and core Trusted Advisor checks. ==No technical support cases.==
- **Developer**: for experimenting and testing. Business-hours email only, general guidance and system-impaired severities only.
- **Business**: the ==lowest plan with 24/7 phone, web, and chat== and full Trusted Advisor. For production workloads. Adds help with common third-party software on EC2 and the AWS Support API.
- **Enterprise On-Ramp**: for business-critical workloads. 30-minute business-critical response, a pool of TAMs for proactive guidance, the Concierge Support Team, and one Infrastructure Event Management engagement per year.
- **Enterprise**: for mission-critical workloads. 15-minute business-critical response, a designated TAM, the Concierge Support Team, Infrastructure Event Management, Well-Architected and operations reviews, and training.
- **Technical Account Manager (TAM)**: an AWS technical expert who gives proactive guidance, reviews your architecture and operations, and coordinates AWS resources for you.
- **Concierge Support Team**: AWS billing and account experts who help with billing questions, invoices, and account best practices.
- **Infrastructure Event Management (IEM)**: short-term AWS guidance to plan and run a big event such as a product launch, a migration, or a sales peak.

> [!tip] Memory hook
> Severity ladder (Business and up): **24, 12, 4, 1** hours. Then **30 minutes** for On-Ramp and **15 minutes** for Enterprise. Developer has only the first two, counted in **business** hours.

Current status: AWS has changed the plan lineup. As of December 2, 2025, Developer and Business Support are no longer available for new subscriptions, and AWS will discontinue Developer, Business, and Enterprise On-Ramp on January 1, 2027 (they remain in AWS GovCloud (US)). On-Ramp customers are being moved to Enterprise Support during 2026. The current plans are Basic, Business Support+ (AI-assisted, 24/7 access, under 30 minutes for critical cases, $29 per month minimum), Enterprise Support (designated TAM, 15-minute response, $5,000 minimum), and Unified Operations (5-minute critical response). For the exam, use the five plans in the table above.

### AWS Support Center

- The console page where you **create and manage support cases**, see case history, and contact AWS.
- Every customer, including Basic, can open **account and billing** cases and **service quota increase** requests there.
- Technical cases need Developer or a higher plan.
- Business and higher can automate cases with the **AWS Support API**.

### AWS Trusted Advisor

- Reference guide: "inspects a user's AWS environment and makes recommendations based on best practices".
- **Check categories**: ==cost optimization, performance, security, fault tolerance, service limits (service quotas)==, and operational excellence.
- Cost optimization examples: idle load balancers, low-utilization EC2 instances, unassociated Elastic IP addresses, underused EBS volumes, RI optimization.
- Security examples available to everyone: S3 bucket permissions, security groups with unrestricted ports, MFA on the root account, IAM use, public EBS and RDS snapshots.
- Basic and Developer get the core checks; Business and above get all checks, plus API access and Amazon EventBridge integration.
- Results show as green (no problem), yellow (investigation recommended), or red (action recommended).

### AWS Health Dashboard and the AWS Health API

- Reference guide: "provides ongoing visibility into resource performance and availability of AWS services and user accounts".
- **Service health**: the public view of the status of all AWS services in all Regions. No sign-in needed.
- **Your account health**: a personalized view of events that affect **your** resources, such as an outage in an AZ you use, scheduled maintenance on your EC2 instances, or expiring certificates, with remediation guidance.
- Formerly two products: the AWS Service Health Dashboard and the AWS Personal Health Dashboard. Now one AWS Health Dashboard.
- **AWS Health API**: programmatic access to the same events, for integration with your own tools. Requires Business, Enterprise On-Ramp, or Enterprise Support. All customers can receive AWS Health events through Amazon EventBridge.
- With AWS Organizations you can turn on an **organizational view** to see events across all accounts.

### AWS Trust and Safety team

- Handles reports of **abuse of AWS resources**: spam sent from AWS, port scanning, denial-of-service attacks, intrusion attempts, malware hosting, phishing sites, and copyright or other objectionable content hosted on AWS.
- Anyone, customer or not, can report abuse with the AWS abuse report form or by email to abuse@amazonaws.com.
- If your own account is the source (for example a compromised instance), AWS Trust and Safety contacts you and you must respond and fix it.
- Do not confuse with AWS Support (help with your account) or AWS Shield (DDoS protection).

### Technical resources on official AWS websites

| Resource | What it is | Use it when |
| --- | --- | --- |
| **AWS documentation** (docs.aws.amazon.com) | User guides, API references, developer guides for every service | You need official how-to or reference detail |
| **AWS whitepapers and guides** | Technical papers by AWS and partners (for example the Well-Architected Framework, How AWS Pricing Works, security best practices) | You want authoritative best-practice or architecture guidance |
| **AWS blogs** | News, announcements, and tutorials, including the AWS Security Blog | You want new features and worked examples |
| **AWS Knowledge Center** | FAQ-style articles written by AWS answering the most common questions and requests AWS Support receives; now hosted on re:Post | You have a common "how do I…" or troubleshooting question |
| **AWS re:Post** | ==AWS-managed community Q&A== that replaced the AWS Forums; answers from the community and AWS experts; free for all | You want to ask the community or search community answers |
| **AWS Prescriptive Guidance** | ==Time-tested strategies, guides, and patterns== from AWS and partners for migration, modernization, and optimization projects | You want a proven step-by-step approach for a migration or a common architecture |
| **AWS Skill Builder and AWS Training and Certification** | Courses and labs | You want to train staff |

### AWS Partner Network (APN)

- The global community of companies that build solutions and services on AWS.
- **Independent software vendors (ISVs)**: build and sell **software** that runs on or integrates with AWS, often through AWS Marketplace.
- **System integrators (SIs)** and consulting or services partners: help customers **design, migrate, build, and manage** workloads. Managed service providers run workloads for customers.
- Customers find partners with the AWS Partner Solutions Finder or through AWS Marketplace.
- **Partner benefits**: partner training and certification, partner events, partner volume discounts, marketing and go-to-market support, funding programs, and specialization badges (AWS Competency programs).

### AWS Marketplace

- Reference guide: "curated digital catalog of third-party software, data, and services".
- Find, buy, deploy, and manage software from ISVs: SaaS, AMIs, containers, machine learning models, data products, and professional services.
- **Cost management**: charges appear on your **AWS bill** (consolidated billing), flexible pricing models (free trial, hourly, monthly, annual, bring your own license), and spend can be tracked with the usual AWS cost tools.
- **Private offers**: negotiated custom prices and terms between a buyer and a seller.
- **Governance and entitlement**: Private Marketplace lets administrators curate an approved product list; license entitlements are tracked (with AWS License Manager).
- Also the place to find third-party security products.

### Technical assistance and engagement options

| Option | What it is | Cue |
| --- | --- | --- |
| **AWS Professional Services** | AWS's own global team of experts who work with you on large projects, such as migrations, using the AWS Cloud Adoption Framework. Paid engagement. | "AWS experts to help deliver a migration", "consulting from AWS itself" |
| **AWS Solutions Architects** | AWS technical experts on your account team who help design architectures and apply best practices | "help designing a solution", "architecture guidance from AWS" |
| **AWS Managed Services (AMS)** | Reference guide: "provides ongoing management for a user's AWS infrastructure": AWS operates it for you (patching, backup, monitoring, incident response, change management) | "AWS to operate our infrastructure", "outsource day-to-day operations" |
| **AWS IQ** | Reference guide: "connects users to AWS Certified experts for help with AWS projects" (freelancers and firms, paid on demand) | "hire a certified freelancer for a short project" |
| **AWS Activate for Startups** | Reference guide: "provides resources to help startups build and grow on AWS": credits, technical support, training | "startup", "AWS credits" |
| **AWS Partners** | Third-party ISVs and SIs | "third-party consulting firm", "third-party software" |
| **TAM** | Technical Account Manager (Enterprise On-Ramp pool, Enterprise designated) | "proactive guidance from a named AWS contact" |

Current status: AWS IQ has reached full shutdown (May 20, 2026, per the AWS General Reference list of services in full shutdown). The exam may still name it.

## Exam traps and commonly confused

| Look-alikes | Distinguishing fact |
| --- | --- |
| Business vs Developer | Business is the **lowest plan with 24/7 phone and chat** and all Trusted Advisor checks. Developer is business-hours email only. |
| Enterprise On-Ramp vs Enterprise | On-Ramp: **30-minute** business-critical response, **pool** of TAMs. Enterprise: **15-minute**, **designated** TAM. |
| Production system down vs business-critical system down | Production down is < 1 hour (Business and up). Business-critical down is < 30 min (On-Ramp) or < 15 min (Enterprise). |
| Basic vs Developer Trusted Advisor | Both get only the **core** checks. Full checks start at Business. |
| Knowledge Center vs re:Post | Knowledge Center is AWS-written answers to common support questions; re:Post is the community Q&A site (Knowledge Center articles now live on re:Post). |
| Prescriptive Guidance vs whitepapers | Prescriptive Guidance gives **actionable patterns and step-by-step guides** for projects such as migrations; whitepapers are broader papers on best practices and concepts. |
| Professional Services vs Solutions Architects vs Partners | Professional Services is a paid AWS delivery team; Solutions Architects are AWS's design advisors; Partners are third-party firms. |
| AWS Managed Services vs AWS IQ | AMS is AWS **operating** your infrastructure ongoing; IQ connects you to **freelance** certified experts for a project. |
| AWS Health Dashboard vs Amazon CloudWatch | Health shows **AWS-side** events (outages, maintenance) affecting you; CloudWatch monitors **your** resources' metrics. |
| Trust and Safety vs AWS Support vs AWS Shield | Trust and Safety handles **abuse reports** about AWS resources; Support helps with your account; Shield protects against DDoS. |
| Service health vs your account health | Service health is public and general; your account health is personalized to your resources. |

> [!warning] Cheapest plan that meets the need
> Questions often say "most cost-effective plan that provides…". Pick the lowest plan that meets every requirement: 24/7 phone → Business; < 30 minutes or a TAM pool → Enterprise On-Ramp; < 15 minutes or a designated TAM → Enterprise.

## Quick self-check

> [!question]- What is the lowest-cost support plan with 24/7 phone access to Cloud Support Engineers?
> Business.

> [!question]- Which plan gives a designated Technical Account Manager?
> Enterprise. (Enterprise On-Ramp gives a pool of TAMs.)

> [!question]- What is the response time for a business-critical system down case on Enterprise On-Ramp, and on Enterprise?
> Under 30 minutes on Enterprise On-Ramp; under 15 minutes on Enterprise.

> [!question]- Which support plans get only the core Trusted Advisor checks?
> Basic and Developer.

> [!question]- Name the five Trusted Advisor categories the exam lists.
> Cost optimization, performance, security, fault tolerance, and service limits (operational excellence was added later).

> [!question]- Someone sees port scans coming from an AWS IP address. Who should they report it to?
> The AWS Trust and Safety team (abuse report form or abuse@amazonaws.com).

> [!question]- Where can you see whether scheduled AWS maintenance will affect your EC2 instances?
> The AWS Health Dashboard (your account health).

> [!question]- A company wants proven step-by-step patterns for migrating a workload. Which resource?
> AWS Prescriptive Guidance.

> [!question]- Name two ways AWS Marketplace helps with cost management and governance.
> Charges appear on the consolidated AWS bill; Private Marketplace limits users to approved products (also private offers and license entitlement tracking).

> [!question]- What is the difference between ISVs and system integrators in the AWS Partner Network?
> ISVs build and sell software; system integrators help customers design, migrate, and build solutions.
